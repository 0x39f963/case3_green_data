Cluster discipline:
- refusal_keeps_sql: public final_sql exists when refusal/abstain should hide SQL.
- unbound_placeholders: `$N` without bindings or EXPLAIN "there is no parameter".
- rag_wrong_example: RAG example outside allowed schema influenced SQL.
- pii_masking: raw PII leak, missing mask, aggregate-vs-PII confusion.
- schema_hallucination: absent table/column or repeated banned identifier.
- retry_non_converge: same SQL hash/error/identifier repeats.
- oracle_mismatch: explicit assertions pass but AST diff still fails.

Use trace_id/case_id evidence. Do not invent files, metrics or labels.
