# Audit Baseline — schema_overlay v1 → v2

## Дата аудита
2026-05-23

## Состояние ДО (v1.0)

| Показатель | Значение |
|---|---|
| Таблиц в схеме | 60 |
| Колонок в схеме | 1872 |
| Таблиц без aliases | 45 / 60 (75%) |
| Таблиц с TODO в business_description | 45 / 60 (75%) |
| Колонок с колоночным уровнем (columns) | 0 / 1872 (0%) |
| Комментариев только на английском | 382 / 1872 (20%) |
| Колонок с пустым комментарием | 5 |

**Вывод:** overlay v1 покрывал только уровень таблиц, без колоночных описаний. 75% таблиц имели незаполненные aliases и TODO-описания. RAG не мог связать NL-запрос типа «активные сотрудники» с колонкой `status` или `is_locked` — отсюда галлюцинации схемы.
